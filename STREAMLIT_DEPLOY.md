# EOC-NET Americas · Streamlit deployment

## Publish on Streamlit Community Cloud

1. Open https://share.streamlit.io/ and connect your GitHub account.
2. Select the private repository **ivanromero0724/COE-regional**, branch **main**, main file **app.py**.
3. Choose an app URL slug, for example `coe-americas-ops`, if available.
4. Deploy. Streamlit Cloud installs packages from `requirements.txt`; no secrets or API credentials are required.
5. Data, labels and the map update when changes to the `data/` files are committed and the app redeploys.

The project does **not** include country fact-sheet generation or 0–100 maturity scores. Formal PDF reports are produced by the survey team separately.

## Inputs

- Live first worksheet in `data/Encuesta_OPS_2026_COEs.xlsx` (one row per institution).
- `data/geografia/paises_americas.gpkg` is the local geographic layer, copied from the El Niño OPS repo.
- Original EOC-NET and PAHO logos in `logos/`.

The companion **PAHO EOC Regional Overview 2026 EN** and **PAHO EOC Country Profiles 2026 EN** were design and methodological references; they are not automatically regenerated by this dashboard. The live Excel is used for calculated figures.

## Interpretation and privacy

- At regional level, each country counts once. Where more than one institution replied (Colombia), a capacity counts as available if either respondent reports it in place; institution-specific views remain separate.
- Each capacity has its own **country denominator**, excluding unreported items. Partial/informal/developing options do not count as functional or established.
- Hazards are ordered frequency ranges, not exact totals. Later questions on networks and cooperation have more limited coverage.
- Results are preliminary and self-reported. No composite maturity scores, five-pillar indices, official rankings, or 0–100 capacity ratings are used.
- The source Excel may include personal respondent details. The dashboard excludes the explicit contact fields. Review free-text response fields before public dissemination.

## Validate locally

```bash
pip install -r requirements.txt
pytest -q tests/test_dashboard_data.py
streamlit run app.py
```

GitHub Actions executes the same tests and smoke-tests the application. Only the Streamlit dashboard is managed in this repository; existing survey reports are maintained externally by their authors.
